Embeddings Models¶

The embeddings models convert each word of an address into a vector that the Seq2Seq network then tags. The AddressParser creates the right embeddings model for its model_type, so you only need these classes to use the embeddings directly or to build your own pipeline:

  • the FastText models ("fasttext" and "fasttext-attention") use FastTextEmbeddingsModel, which reads the French fastText .bin embeddings,

  • the FastText Light models ("fasttext-light") use MagnitudeEmbeddingsModel, which reads the same embeddings in the Magnitude format,

  • the BPEmb models ("bpemb" and "bpemb-attention") use BPEmbEmbeddingsModel, which uses the byte-pair multilingual subword embeddings.

The FastText .bin embeddings are read by FastTextBinReader, our own reader of the fastText binary format. It gives the same vectors as the fasttext package without depending on fasttext nor gensim, and its input matrix is memory-mapped: it loads in a few seconds, only the rows used are kept in RAM, and the data loading workers share its memory. It replaces the fasttext/gensim loader used up to version 0.11.0.

FastText Binary Reader¶

class deepparse.embeddings_models.FastTextBinReader(path: str)[source]¶

Reader of the Facebook fastText .bin format (version 12, non-quantized, unsupervised models) that computes word vectors like FastText::getWordVector without the fasttext or gensim packages.

The input matrix is memory-mapped, so loading is fast, the RAM usage stays low, and the pages are shared between processes (e.g. DataLoader workers). When pickled, only the path and the parsed dictionary are kept, and the memory map is reopened on unpickling.

Parameters:

path (str) – Path to the fastText .bin file.

get_subword_ids(word: str) → List[int][source]¶

Return the input matrix rows used to compute a word vector, like Dictionary::getSubwords: the word id (if the word is in the vocabulary) followed by the bucket rows of its hashed character n-grams.

get_word_vector(word: str) → ndarray[source]¶

Compute the vector of a word as the mean of its subword rows, or a zero vector if it has none.
