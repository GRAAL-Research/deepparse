Pretrained Models Results¶

This page reports the accuracy of our pretrained models per country. The memory usage and the inference time of each model are reported in the Parser page, and Choose a Model summarizes how to pick a model.

We evaluate our models on two forms of address data

  • clean data which refers to addresses containing elements from four categories, namely a street name, a municipality, a province and a postal code,

  • incomplete data which is made up of addresses missing at least one category amongst the aforementioned ones.

You can get our dataset on the HuggingFace Hub here (one configuration per country). The data protocol is described in the deepparse-address-data repository.
