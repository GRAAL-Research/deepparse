Choose a Model¶

Deepparse offers pretrained models built on two embeddings, FastText and BPEmb, each with or without an attention mechanism, plus a lighter FastText version. You select one with the model_type (and attention_mechanism) argument of AddressParser. All the figures below come from this documentation; their source is given under each table.

Model Types¶

model_type

Alias

Description

"fasttext"

"fastest"

Seq2Seq model using the French fastText pretrained embeddings. The "fastest" alias is the quickest model to process one address.

"fasttext-attention"

The "fasttext" model with an attention mechanism. Requires attention_mechanism=True (same model as model_type="fasttext", attention_mechanism=True).

"fasttext-light"

"lightest"

The FastText model using the Magnitude embeddings mapping, which reduces the memory footprint. The "lightest" alias is the model using the least RAM and GPU memory.

"bpemb"

"best"

Seq2Seq model using the byte-pair multilingual subword pretrained embeddings. The "best" alias (the default model_type) is described as the best accuracy performance.

"bpemb-attention"

The "bpemb" model with an attention mechanism. Requires attention_mechanism=True (same model as model_type="bpemb", attention_mechanism=True).

Source: the model_type argument of AddressParser and the model names accepted by the parser (case-insensitive).

Accuracy and Multilingual Coverage¶

All the models were trained on addresses from the same 20 countries; the Pretrained Models Results page gives their accuracy on those countries and a zero-shot evaluation on 41 other countries.

  • FastText uses French word embeddings with character n-grams. On the 20 training countries (clean data), it reaches 98.9% to 99.97% accuracy (see Pretrained Models Results).

  • BPEmb uses multilingual subword embeddings, which cover the vocabulary of many languages. On the 20 training countries (clean data), it reaches 96.97% to 99.99% accuracy (see Pretrained Models Results).

  • Attention mechanism: it improves the accuracy by around 0.5% on the training countries, and it further improves the zero-shot accuracy on most of the 41 other countries (see the attention table of Pretrained Models Results).

  • FastText Light: on average, its results are about 2% lower on the training countries, but similar on the zero-shot countries (see the Parser page and our article).

When to Use Each Model¶

  • You parse addresses from the 20 training countries and want the quickest model: "fasttext" ("fastest"). Its embeddings take the most disk space (6.8 GO).

  • You parse addresses from other countries (zero-shot): prefer a model with an attention mechanism ("fasttext-attention" or "bpemb-attention") and check the country in the zero-shot tables of Pretrained Models Results, since the accuracy varies a lot between countries.

  • Disk space is limited (e.g. a container image or a small node): "bpemb" or "bpemb-attention", whose embeddings take 116 MB.

  • You want the default model: "bpemb" ("best").

  • You want the FastText model with a lower memory footprint: "fasttext-light" ("lightest"). Note that a FastText Light model cannot be retrained nor tested, and cannot use data loading workers (num_workers > 0) on Windows (see FastTextModelError).

  • You need to retrain a model on new data or new tags: any model except "fasttext-light" (see the Training Guide).
